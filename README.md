## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ShahbazAhmad08/Ar-Wishwas-Developer-LLP.git

# Navigate to project folder
cd Ar-Wishwas-Developer-LLP

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
